# Log Processing

Scripts and notebooks for processing logs to create run summary plots and reports

## Contents

### Standalone Programs

 * `envPlot.py` - plot LBT weather data (time series and wind rose) for a night
 * `gcsPlot.py` - plot LBT guider data for a night

### Jupyter Notebooks

 * `envPlot.ipynb` - development notebook for `envPlot.py` with detailed notes
 * `gcsPlot.ipynb` - development notebook for `gcsPlot.py` with detailed notes
 * `windRise.ipynb` - notebook to experiment with making wind rose plots
